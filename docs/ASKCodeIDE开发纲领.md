## 二、核心功能

### 2.1 编程支持

- **Verilog**: 硬件设计、FPGA开发
- **Rust**: 系统编程、固件开发
- **JavaScript**: 应用开发、测试脚本

### 2.2 编译工具链

1. **ASK综合器**: Verilog → 网表
2. **ASK编译器**: Rust/JS → RISC-V机器码
3. **ASK链接器**: 目标文件 → 可执行文件

### 2.3 烧录支持

- JTAG烧录 (FPGA配置)
- 串口烧录 (固件更新)
- USB烧录 (智能数卡)

### 2.4 调试工具

- 波形查看器
- 串口终端
- 性能分析
- 断点调试

## 三、ASK综合器设计

### 架构

1. 前端解析: Verilog → AST
2. 优化引擎: 常量传播、死代码消除
3. 映射器: 映射到FPGA原语
4. 输出: 网表文件(.vg)

### 技术栈

- 开发语言: Rust
- 解析器: tree-sitter
- 优化器: 自研基于LLVM IR

### 开发阶段

- 阶段1 (3月): 基础综合
- 阶段2 (3月): 高级优化
- 阶段3 (3月): FPGA支持

---

## 四、ASK编译工具链

### 组件

1. **ASK-Rust**: Rust → RISC-V
2. **ASK-JS**: JavaScript → WASM → RISC-V
3. **ASK-Link**: 链接器
4. **ASK-Obj**: 对象工具

### 技术栈

- Rust编译: 基于rustc后端
- JS编译: 基于LLVM + QuickJS
- 链接器: 自研ELF格式

---

## 五、ASKCode IDE架构

### 技术栈

- 框架: Electron
- 编辑器: Monaco Editor (VSCode核心)
- UI: React + TypeScript
- 后端: Node.js + Rust

### 核心功能

1. 代码编辑 (语法高亮、智能补全)
2. 项目管理 (模板、依赖、配置)
3. 编译综合 (一键编译、实时错误)
4. 烧录调试 (JTAG、串口、波形)
5. 仿真测试 (软件、硬件、覆盖率)
